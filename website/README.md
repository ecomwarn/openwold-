# OpenWolf SaaS Website

A standard SaaS-style marketing website for OpenWolf. Pure static HTML/CSS/JS — no build step or dependencies.

## Sections

- Sticky navbar with mobile menu
- Hero with terminal mockup and CTAs
- Social-proof logo strip
- Animated stats counters
- Feature grid (6 cards)
- "How it works" steps
- Pricing with monthly/yearly toggle
- Testimonials
- FAQ accordion
- CTA banner and footer

## Run locally

```bash
cd website
npx serve .
# or
python3 -m http.server 8080
```

Then open http://localhost:8080.
